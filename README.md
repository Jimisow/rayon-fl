# Rayon Fruits & Légumes

Application interne pour l'équipe du rayon fruits et légumes : gestion des produits (avec génération de code-barres Code128 pour le pad de scan), planning hebdomadaire (grille de saisie manuelle), et notes d'équipe. React + Vite, Firebase Firestore (avec persistance hors-ligne).

## Développement local

```bash
npm install
npm run dev
```

## Déploiement

Le déploiement sur GitHub Pages est automatique via GitHub Actions à chaque push sur `main` (voir `.github/workflows/deploy.yml`).
